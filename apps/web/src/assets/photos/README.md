# Photos

Drop the site's lifestyle photos here, named exactly as below. Until a file exists, the page shows a labelled placeholder at the same size, so nothing shifts when the real photo arrives.

| File | Where it's used | Aspect / min size |
|---|---|---|
| `problem.jpg` | Home, Problem section | 21:9, at least 2400×1030 |
| `closing.jpg` | Home, closing call to action | 16:9, at least 2000×1125 |
| `og.jpg` | Social-share image background | 1200×630 exactly |

JPEG, sRGB, under 5 MB, no text baked in, no readable personal data on receipts. Full guidelines: [`docs/DESIGN.md` §6.1](../../../docs/DESIGN.md#61-photo-slots).
